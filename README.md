# Foliokit

A developer portfolio that works out of the box. Everything you see is driven by
a single config file — no database, no backend, no environment variables.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:8889 and edit `portfolio.config.ts`. Your name, bio,
projects, socials and theme all live there.

## Scripts

| Command         | Description                    |
| --------------- | ------------------------------ |
| `npm run dev`   | Dev server on port 8889        |
| `npm run build` | Static export to `./out/`      |
| `npm run lint`  | ESLint                         |
